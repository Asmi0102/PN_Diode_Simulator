info About This Tool

PN-Sim v2.0 is an interactive, browser-based semiconductor simulator for laboratory analysis and education. It models the current-voltage (I-V) characteristics of a PN junction diode using the Shockley Ideal Diode Equation, with real-time temperature dependence, 12 built-in semiconductor materials, a custom material editor, and Zener/avalanche reverse breakdown modelling.

All calculations run entirely in the browser — no server or build step. The voltage slider range expands automatically for wide-bandgap materials (SiC, GaN, ZnO, Diamond) so the diode always reaches its conduction region regardless of cut-in voltage.

functions Physics & Formulas

Shockley Ideal Diode Equation

I = Is · (exp(V / (n · Vt)) − 1)
I — diode current (A)
Is — reverse saturation current (A)
V — applied voltage (V)
n — ideality factor = 1.5
Vt — thermal voltage (V)

Thermal Voltage

Vt = kT / q
k = 1.38 × 10−23 J/K  (Boltzmann constant)
q = 1.60 × 10−19 C  (Electron charge)
T = Junction temperature (K) — slider range 200–400 K
At 300 K → Vt ≈ 25.85 mV  ·  At 400 K → Vt ≈ 34.47 mV

Ideality Factor (n) — fixed at 1.5

n = 1.5

n = 1: ideal diffusion-only.  n = 2: recombination-dominated.  n = 1.5 is a realistic mid-point for practical diodes.

Reverse Breakdown Model (Reverse Bias Mode only)

Ibreak = −2 · exp((|V| − Vbr) / 0.05)

Activates when V < −Vbr. Toggle Biasing State to Reverse to expose this region.

v2.0 fix

Dynamic Voltage Slider Range

Vmax = ceil( max(2.0, Vcut + 0.5) × 2 ) / 2

The slider max auto-expands to at least 0.5 V above Vcut, rounded to the nearest 0.5 V. Fixes Status and Efficiency always showing OFF/0% for SiC, GaN, ZnO, and Diamond.

help_outline How to Use

  1. 01. Select a semiconductor material from the dropdown. Band gap, Is, Vcut, curve colour, and the voltage slider range all update instantly.
  2. 02. Drag the Bias Voltage slider. The range auto-expands for wide-bandgap materials — SiC reaches +3.5 V, Diamond reaches +5.0 V — so Status and Efficiency always respond correctly for every material.
  3. 03. Adjust Junction Temperature (200–400 K). Vt = kT/q recalculates live and the Graph Summary updates simultaneously.
  4. 04. Toggle Biasing State to Reverse Bias to activate Zener/avalanche breakdown on the chart.
  5. 05. Click Material Library in the nav bar (or mobile sidebar) to view all 12 built-in materials and add your own. Custom entries appear in the simulator dropdown immediately, marked with ★.
  6. 06. Use the zoom in / zoom out buttons in the chart toolbar to inspect any region in detail. The grid toggle hides/shows chart grid lines.
  7. 07. Click Export Data (header) or Quick Export → CSV to download a 400-point I-V dataset. Use PDF Report to print.
  8. 08. Click Reset in the header to restore all defaults — Silicon, +0.75 V, 300 K, Forward Bias.
  9. 09. On mobile, tap the ☰ icon (top-left) to open the navigation sidebar with links to Material Library, Documentation, and all sections.
